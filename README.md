# QuantVoyager Pipeline Viewer

A self-contained HTML dashboard showing the **data collection pipeline** of [QuantVoyager](https://github.com/kangjinghang/QuantVoyager) — a quantitative trading platform for Chinese convertible bonds and PEAD strategies.

This repo only hosts the **static visualization page**. The source project stays private.

## Contents

- `index.html` — 23 pipeline tasks (东财/新浪/集思录/同花顺/腾讯 → MySQL), 4 live capture samples, 20 table schemas. Zero secrets, zero row-level data.

## Update

Regenerated from server-side telemetry whenever the pipeline runs. Open `index.html` directly in a browser, or view via GitHub Pages:

**🔗 https://kangjinghang.github.io/quantvoyager-pipeline/**

## How it's built

Generated by `tools/generate_pipeline_doc.py` in the main project from three sources:
1. `tools/pipeline_registry.py` — task definitions (source URL, schedule, target table)
2. `pipeline_capture.log` — live HTTP request/response samples
3. MySQL — table schemas + row counts
